Skill-Gap Analysis

Team Skills Compared With Analytics Job Postings in NAICS 5415

Purpose

This page compares the skills requested in our analytics job postings with the current skills of our three team members. It answers two supporting questions from the Project Foundation page:

  • Where does the target user have skill gaps?
  • Which skills should the target user prioritize?

We use our own team as three realistic examples of the target user: early-career candidates moving into analytics roles within Computer Systems Design and Related Services (NAICS 5415).

WarningData Limitation: Truncated Skill Lists

As documented on the Data Preparation page, the skill fields in the source extract were alphabetically truncated before delivery. No skill name in the dataset begins with a letter after C. Python, SQL, Excel, Tableau, Power BI, and R therefore never appear in the posting data, even though they are core analytics tools.

To keep the analysis honest, we separate the skills into two groups:

  • Market skills: measured directly from our 287 job postings.
  • Core tools: added from outside evidence (Verma et al. 2019) because the dataset cannot measure them. Their demand is assumed, not measured.

2. Skills Requested in Job Postings

We extracted skills from the SKILLS_NAME field of the cleaned panel. Each posting stores its skills as a list, so we count how many postings mention each skill rather than total mentions. This stops a single long posting from inflating a skill’s importance.

Grouping Related Skill Names

Many skill names in the source data describe the same capability (“Analytics”, “Advanced Analytics”, “Business Analytics”). We grouped related names into the skills our team rated, so that team ratings and market demand refer to the same thing.

Show code 
SKILL_GROUPS = {
    "Analytics": ["Analytics", "Advanced Analytics", "Business Analytics",
                  "Analytical Skills", "Analytical Thinking"],
    "Automation": ["Automation", "Business Process Automation"],
    "Business Intelligence": ["Business Intelligence", "Business Intelligence Tools",
                              "Business Reporting"],
    "Business Requirements": ["Business Requirements", "Business Analysis",
                              "Business Process Analysis"],
    "Airflow": ["Airflow", "Apache Airflow"],
    "Big Data": ["Big Data", "Big Data Analytics", "Apache Hadoop"],
    "BigQuery": ["BigQuery"],
    "Algorithms": ["Algorithms"],
    "Artificial Intelligence": ["Artificial Intelligence", "AI Agents", "Agentic AI"],

    "Apache Spark": ["Apache Spark"],

demand = pd.Series(
    {
        skill: panel["skills"].map(lambda s, names=names: bool(s & set(names))).sum()
        for skill, names in SKILL_GROUPS.items()
    },
    name="Postings",
)
demand = demand.to_frame()
demand["Share of postings (%)"] = (demand["Postings"] / postings_with_skills * 100).round(1)
demand = demand.sort_values("Postings", ascending=False)

3. Comparing Team Skills With Market Requirements

Job postings list skills but not the proficiency level employers expect. To compare the two, we set a target level for each skill using a transparent rule based on how often the skill is requested:

Demand in postings Target level
20% or more of postings 4 (Advanced)
10% to 19.9% 3 (Intermediate)
Under 10% 2 (Basic knowledge)
Core tools (assumed, not measured) 4 (Advanced)

Core tools receive a target of 4 because the analytics-skills literature consistently identifies SQL, Excel, visualization tools, and a programming language as baseline expectations for analyst roles (Verma et al. 2019).

For each member and skill:

  • Gap = target level − current rating (0 if the member already meets the target)
  • Priority score = average team gap × demand weight, where the demand weight is the posting share for market skills and a fixed 0.5 for core tools

The priority score favors skills that are both widely requested and weak across the team.

Show code 
def target_level(share):
    if share >= 20:
        return 4
    if share >= 10:
        return 3
    return 2


targets = demand["Share of postings (%)"].map(target_level)
for tool in CORE_TOOLS:
    targets[tool] = 4

demand_weight = (demand["Share of postings (%)"] / 100).reindex(targets.index)
demand_weight[CORE_TOOLS] = 0.5  # assumed; see callout at top of page

member_gaps = (targets - df_skills[targets.index]).clip(lower=0)  # members x skills

gap_table = pd.DataFrame(
    {
        "Skill type": ["Core tool" if s in CORE_TOOLS else "Market skill" for s in targets.index],
        "Demand (%)": demand["Share of postings (%)"].reindex(targets.index),
        "Target level": targets,
        "Team average": df_skills[targets.index].mean().round(2),
    }
)
gap_table = gap_table.join(member_gaps.T.add_suffix(" gap"))
gap_table["Average gap"] = member_gaps.mean().round(2)
gap_table["Priority score"] = (gap_table["Average gap"] * demand_weight).round(2)
gap_table = gap_table.sort_values("Priority score", ascending=False)

# Saved for the improvement plan (Section 4)
gap_table.to_csv("data/processed/skill_gap_table.csv", index_label="Skill")

Key Findings

Top five priority skills: Python, SQL, Tableau / Power BI, Automation, Excel
Targets already met by the whole team: Analytics, Big Data, A/B Testing
Total levels to close per member: Jenna 19, Mariam 24, Juan 14
  1. The team matches the market’s most common request. Analytics, the skill in about two-thirds of postings, is already at the Advanced target for all three members. Our business-facing strengths are real and relevant.
  2. The core tools are the biggest gap. SQL, Python, and visualization tools are baseline expectations for analyst roles, and Jenna and Mariam are both at Beginner or Basic level in SQL and Python. Because the dataset cannot measure them, this finding relies on outside evidence, but it is the gap most likely to block a job application.
  3. Automation and pipeline tools are the largest measured gap. Automation (about 28% of postings) and Airflow (about 17%) are requested often, and the whole team rates at or near Beginner. These reflect the data-engineering side of NAICS 5415, where Database Architects make up a third of postings.
  4. The team is complementary. Jenna’s Excel and BI skills, Mariam’s business-requirements skills, and Juan’s coding skills cover different parts of the market. Peer teaching inside the team is a realistic first step before outside courses.
  5. Juan is closest to the largest segment. Data Scientists are 47% of postings and the highest-paid group (see Market Baseline). Juan’s remaining gaps are smaller and more technical, while Jenna and Mariam need a longer foundation in SQL and Python before those roles are within reach.

Limitations

  • Truncated skills: Only skills beginning with A–C are observable. Rankings would likely change if Python, SQL, and other D–Z skills were visible.
  • Assumed targets: Postings do not state a proficiency level. The target-level rule and the core-tool weight are team assumptions, stated above so readers can adjust them.
  • Self-ratings: Team ratings are self-assessed and not independently tested.
  • Small groups: Business Intelligence Analysts have only five postings, so role-specific demand for BI roles cannot be estimated reliably.
