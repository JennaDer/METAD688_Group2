# Outputs

The project's exported outputs are kept next to the code that produces them:

- `data/processed/career_market_panel.csv`: the cleaned analytical panel (1,790 postings)
- `data/processed/career_market_data_dictionary.csv`: the data dictionary
- `data/processed/panel_build_stats.json`: counts recorded at each filtering step
- `data/processed/skill_gap_table.csv` and `team_skills_v2.csv`: skill-gap outputs and team ratings
- `data/processed/model_metrics.csv` and `model_coefficients.csv`: Step 4 model results
- `figures/`: every chart used on the website and in the report
- `final_report.docx`: rendered from `final_report.qmd` and published with the site
